# Limitations and future improvements

This document distinguishes verified implementation constraints from risks that need further validation. The project is a local learning demonstration, not a production recruitment system.

| Limitation | Why it matters and current effect | Possible next step (not implemented) |
| --- | --- | --- |
| Small synthetic dataset (20 profiles, five jobs, 100 labels) | Metrics and UX exercise the complete workflow but cannot establish general quality, statistical significance, production performance, or candidate outcomes. | Secure appropriately governed, consented evaluation data or a clearly licensed benchmark; expand query/job coverage. |
| No real-world relevance or eligibility ground truth | Manual relevance grades reflect author judgments. Eligibility is not measured against an independent labeled set. | Use multiple trained reviewers, independent adjudication, label guidelines, and separately measured eligibility outcomes. |
| Subjective relevance labels and possible bias | Human-authored criteria, synthetic archetypes, and evidence selection can encode assumptions or demographic/systematic bias. | Audit labels and criteria; collect disagreement/rater measures; test outcomes for proxy effects with responsible governance. |
| Embedding model and representation limitations | Model choice, language/domain coverage, chunk strategy, and digest alter nearest-neighbor results. No superiority or quality benchmark is established. | Compare model versions and chunking against held-out judgments; persist experiment settings and confidence intervals. |
| Retrieval quality limitations | English FTS tokenization/stemming can miss paraphrases and technical tokens. Exact pgvector scan is O(number of chunks) and only practical for the current small corpus. | Measure recall/latency at larger corpus sizes; evaluate tokenization, chunk selection, and index options before scaling. |
| Subjective deterministic ranking weights and heuristics | Weights (30/30/20/10/10) and thresholds are authored choices, not learned or calibrated. Reproducibility does not imply validity. | Conduct documented sensitivity analysis and domain review; validate on independent judgments and monitor group impacts. |
| LLM hallucination and prompt injection risks | Schema/reference checks and 55% token overlap heuristic are not semantic entailment. Valid evidence can be misrepresented; a correct paraphrase may fail. Prompt separation is not a sandbox. | Keep human review; improve claim-level entailment testing and adversarial testing without allowing explanation output to set decisions. |
| Candidate-data quality variability | Invalid persisted profile rows are individually skipped, but valid shape does not guarantee factual accuracy, completeness, or consistent source data. | Add provenance/import review and data-quality policies before using any real data. |
| Privacy, security, and governance not production-ready | No authentication/authorization, consent, retention/deletion workflow, tenant isolation, rate limiting, or production secret management is implemented. Candidate profiles are synthetic, but the design should not be assumed safe for real CVs. | Define access control, lawful basis, consent, deletion, encryption, audit, secret handling, and threat model before real data. |
| No production-scale load test or operational SLO | The integration suite is local and small. It does not measure concurrent workloads, DB saturation, provider queues, or recovery objectives. | Establish representative load tests, request budgets, connection pooling, telemetry and recovery procedures. |
| Fixed 768-dimensional vector column | A model with another dimension is rejected; migration is required to switch dimensions. | Make model/dimension migrations deliberate and testable; avoid mixing vector spaces. |

These proposals are future work and are not current application capabilities. For implementation-specific exposure see [failure handling](engineering/failure-handling.md); for prioritization see the [architecture review](architecture-review.md).
